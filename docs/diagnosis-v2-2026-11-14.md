# 诊断包 v2

实时采集和批注快照经同一个规范化函数生成相同顶层字段，缺失值以 null 或空数组表示，并在 missing 说明。completeness 反映实际证据完整度；旧记录在读取时转换。保留旧版 source、partial 与 hitTest，供现有消费者使用。

摘要由本地规则生成，先写症状，再按目标 pointer-events、命中覆盖顺序列出字段证据；仅在有效命中测试中未发现覆盖时写出该排除项。缺失证据列于摘要并可在 missing 查原因。目标样式单独采集，因为 pointer-events: none 的元素不一定出现在命中链中。命中链来自 elementsFromPoint 的顺序，排除扩展自身，最多八项；它是命中堆栈，不是 DOM 祖先链。

读取接口首先返回摘要文本块，第二块返回 JSON。旧数据缺少新证据时不会伪造。测试使用 happy-dom 和模拟命中，不代表真实浏览器或扩展端到端验收。跨域 iframe、遮挡发生原因及网络或脚本根因未自动定性；长摘要有长度限制，详细缺失原因见 missing。
