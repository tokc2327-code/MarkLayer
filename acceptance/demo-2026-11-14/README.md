# 演示视频说明

[观看 10 秒视频](demo.mp4)。这是一次本地 Guide 演示的 20 张过程截图，以 2 fps 合成，无声音、无鼠标轨迹；不是连续实时录屏。视频未展示 Pair 模式，也未证明真实 agent 监听事件。完整通过与未覆盖范围见 [RESULTS.md](RESULTS.md)。

| 视频时间 | 实际动作 |
| --- | --- |
| 0:00–1.5 | 脚本经 MCP 开始两步演示，第一步高亮评论工具。 |
| 1.5–2.5 | 误选画笔，第一步仍显示。 |
| 2.5–4.5 | 点击暂停、继续，脚本发送对应状态。 |
| 4.5–6 | 点击下一步，脚本发送第二步，矩形工具高亮。 |
| 6–8.5 | 受控断网并关闭 WebSocket，随后恢复；画面依次显示离线和在线。 |
| 8.5–10 | 恢复后脚本发送第二步新字幕，页面显示该字幕。 |

本次本地 Worker 监听 5199，D1 迁移使用 `--local`；页面使用 Example Domain。复现脚本需要 Playwright MCP 的 `browser_run_code_unsafe` 和已构建的本地 Worker。`run.json` 记录真实返回，脚本操作与网络控制均为自动化。
